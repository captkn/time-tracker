Time Tracker – Blazor

A personal project exploring Blazor and modern .NET web development through a practical time-tracking application.

Project Goals

This project combines two objectives:

* Develop a useful application for tracking working time.
* Explore Blazor’s component model, application structure, and development experience.

Technology

* C#
* .NET
* Blazor

Development Approach

This is an experimental project focused on learning, evaluating technologies, and incrementally building useful functionality.

I’m also exploring an alternative implementation using React and TypeScript to gain practical experience with different frontend development approaches.

Status

Work in progress. This repository is primarily a personal learning and experimentation project rather than a production-ready application.
